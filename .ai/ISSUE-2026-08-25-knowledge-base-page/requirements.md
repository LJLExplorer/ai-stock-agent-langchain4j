# 知识库管理页面需求

## 背景

当前前端只有股票问答页面，系统已经具备 RAG 知识文档的后端能力。用户需要一个可跳转的知识库页面，用于录入和管理会参与 RAG 检索的知识文档，并能随时返回正常问答。

## 目标

新增一个基于标准 React Router 的知识库管理页面，实现真实的知识文档新增、查看、禁用和删除；保持问答页面可正常访问，并为未来扩展其他页面预留路由结构。

## 功能要求

1. 顶部提供“问答”和“知识库”导航，当前页面有明确的激活状态。
2. 知识库页面支持新增文档：标题、文档类型、标签、正文内容。
3. 新增文档调用后端接口，后端完成文本切块、向量化、写入 MongoDB 和 Milvus。
4. 知识库页面展示文档列表，至少显示标题、类型、标签、分块数量、更新时间和启用状态。
5. 支持禁用文档。禁用后文档保留在管理列表中显示为已禁用，并且不能继续被 RAG 检索。
6. 支持删除文档。删除前需要确认，删除失败时保留列表状态并给出可理解的错误信息。
7. 新增、禁用、删除成功后刷新列表并提供成功反馈；请求过程中按钮显示忙碌状态，避免重复提交。
8. 页面在窄屏下可用，不产生横向滚动；交互控件具备键盘焦点和可访问名称。

## 接口约定

- `POST /api/knowledge/documents`：新增文档。
- `GET /api/knowledge/documents`：查询管理列表，包含启用和已禁用文档。
- `POST /api/knowledge/documents/{documentId}/disable`：禁用文档，并清理对应向量。
- `DELETE /api/knowledge/documents/{documentId}`：删除文档及对应向量。

## 非目标

- 本次不实现文档编辑、重新启用、文件上传、飞书同步 UI。
- 本次不改造问答页的既有会话和聊天逻辑。

## 验收标准

- 可从问答页进入知识库页，也可从知识库页返回问答页；浏览器前进、后退和直接访问路由可用。
- 新增一篇文档后，列表中可看到该文档及其处理结果。
- 禁用后该文档仍在列表中但状态变为已禁用，且其向量不再参与 RAG 检索。
- 删除后文档从列表消失，MongoDB 记录和向量均被清理。
- 前端构建通过，后端相关测试通过。
