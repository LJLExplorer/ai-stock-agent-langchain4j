#### ✅ B004: factCheck置信度计算错误 - 已修复
**文件**: `RagPipelineService.java`
**修改内容**:
- 修复置信度计算公式
- 无检索结果时置信度为0（原为0.5）
- 有结果无匹配时置信度为0.3
- 部分匹配时置信度 = (matchCount/total) * 0.7 + 0.3

**关键改进**:
```
原: confidence = empty ? 0.5 : min(1.0, matchCount/size + 0.3)
新: confidence = empty ? 0 : (matchCount > 0 ? matchCount/size*0.7 + 0.3 : 0.3)

置信度范围变化:
- 无结果: 0.5 → 0 (更保守)
- 无匹配: 可能1.0 → 0.3 (更正确)
- 完全匹配: 1.3(错误,被capped) → 1.0 (正确)
```

**验证**:
- 置信度范围[0.0, 1.0] ✓
- 逻辑清晰有注释 ✓
- 编译通过 ✓
