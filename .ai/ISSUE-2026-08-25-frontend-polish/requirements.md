# 前端体验优化需求

## 目标

改善股票研究工作台的视觉层次与对话操作体验，并支持删除历史会话。

## 已确认范围

- 基于现有 React 与 CSS 实现，不引入 shadcn/ui 或新的 UI 组件依赖。
- 优化现有页面的配色、间距、圆角、阴影、层次和移动端表现。
- 历史会话增加删除按钮，删除前二次确认；删除当前会话后清空当前对话并刷新列表。
- 消息列表保持独立滚动，避免整页被消息内容拉到底。
- 用户输入框设置合理最大高度，内容过长时在输入框内部滚动。

## 成功标准

- 删除会话会真正删除后端会话及其消息，并按用户 ID校验归属。
- 消息区可以独立上下滚动，页面整体布局保持稳定。
- 输入较长内容时 textarea 不无限撑高，仍可在内部查看和编辑全文。
- 现有发送、加载历史、新建会话、RAG 和工具开关功能不受影响。
