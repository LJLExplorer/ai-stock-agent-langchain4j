# 前端体验优化设计

## 方案

沿用现有三栏工作台结构，在 `App.jsx` 增加会话删除动作，在 `ChatController` 与 `ChatService` 增加按用户校验的删除入口，在 `styles.css` 统一调整视觉 token 和滚动容器行为。

## 数据流

历史会话项上的删除按钮调用 `DELETE /api/chat/sessions/{sessionId}?userId=...`。成功后从本地列表移除；若删除的是当前会话，则同时清空 `sessionId`、消息和执行详情。删除按钮阻止冒泡，避免触发会话切换。

## 交互与视觉

- 保留清晰的主色和状态色，提升页面背景、面板、标题和操作按钮的层级对比。
- 历史会话项采用“内容 + 悬停显示删除操作”的紧凑布局。
- `.conversation` 使用受限高度，`.message-list` 使用 `min-height: 0` 与 `overflow-y: auto` 独立滚动。
- composer textarea 使用固定最小高度和最大高度，内容超出时 `overflow-y: auto`。
- 桌面端保持三栏，窄屏隐藏检查栏并让主对话区优先可用。

## 错误处理

删除失败保留列表和当前会话不变，并提示接口错误；删除进行中禁用重复操作。后端找不到或不属于当前用户的会话返回无权限/不存在错误，不执行删除。
