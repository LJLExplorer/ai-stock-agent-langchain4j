# Agent Planner 需求

## 背景

当前股票助手由 LangChain4j `AiServices` 直接根据工具描述自主选择工具。需要增加一个结构化规划层，先把股票分析问题转换为受控任务计划，再执行必要的工具。

## 范围

第一版只支持股票分析，不覆盖组合分析、股票对比、趋势预测、选股等其他意图。

## 功能需求

1. Planner 识别股票分析意图、股票代码和分析任务。
2. 计划必须经过 `PlanValidator` 校验后才能进入执行阶段。
3. 任务使用枚举表示，并通过集中映射转换为允许的工具集合。
4. 执行阶段按已校验任务裁剪工具集，不能把非法任务或未映射任务传递给 Agent。
5. Planner 返回非法 JSON、未知意图、非法任务、缺少股票代码或调用失败时，安全降级到现有 Agent 流程。
6. `enableTools=false` 时不得执行任何规划工具链，保持当前无工具行为。
7. 现有会话记忆、RAG、工具调用记录和响应结构保持兼容。

## 验收标准

- 合法股票分析计划可得到稳定的任务集合和裁剪后的工具集合。
- 未知任务、空任务、重复任务、错误意图和缺少标的均会被拦截。
- Planner 异常不会导致聊天请求失败。
- 现有测试和新增 Planner/Validator/ChatService 测试通过。
