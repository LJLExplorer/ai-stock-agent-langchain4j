# 知识文档详情与来源跳转需求

## 背景

知识库管理页目前只显示文档标题和元数据，无法查看原始正文。问答中的知识来源统一使用 `documentUrl` 新标签打开；内部知识文档没有外部 URL，点击后会打开无内容页面。

## 目标

提供只读知识文档详情页，使用户可从知识库列表和问答来源查看文档完整正文；网页来源仍跳转到其外部原文。

## 功能要求

1. 知识库文档标题可点击并进入 `/knowledge/documents/:documentId`。
2. 详情页展示标题、类型、标签、启用状态、分块数量、创建时间、更新时间和完整原始正文。
3. 详情页提供返回知识库的入口，并支持浏览器刷新和直接访问。
4. 后端提供按 ID 查询活动知识文档的接口，找不到或已删除时返回 404 与明确错误信息。
5. 问答中的非网页知识来源跳转到对应的内部详情页，使用当前标签页。
6. `WEB` 来源且具备有效外部 URL 时，保留新标签打开原文的行为。
7. 不新增编辑、重新切块或上传能力。

## 验收标准

- 点击知识库列表标题可看到该文档的完整正文和元数据。
- 点击问答中内部知识来源可进入同一文档详情页，不再出现空白新页面。
- 点击网页来源仍打开其外部原文。
- 无效或已删除 ID 显示清晰的未找到状态，且不造成页面崩溃。
- 前端构建及相关后端测试通过。
