# 代码审查问题修复设计

## 方案

- `ChatService` 分离 `originalUserMessage` 与发送给模型的 `promptUserMessage`，业务消息和会话标题使用原始问题。
- `ShortTermSummaryService` 先替换消息窗口，成功后写摘要及索引；消息更新失败时不写摘要。摘要写入失败时保留可重试状态并抛出异常。
- `LongTermMemoryService` 将向量检索候选数扩大到足够覆盖用户过滤结果，并继续按用户、启用状态过滤；不改变向量元数据结构。
- 控制器使用安全的 `instanceof` 校验，非法请求统一返回 400，避免类型转换异常变成 500。

## 测试

为反馈控制器、聊天历史、摘要失败路径、长期记忆召回过滤和知识库请求校验分别增加单元测试；最后执行全量 Maven 测试。
