# 代码审查问题修复需求

## 目标

修复当前代码审查发现的输入校验、聊天历史污染、短期摘要一致性和用户记忆召回问题，并补充回归测试。

## 范围

1. 反馈详情类型非法时返回 400。
2. 业务聊天历史保存用户原始问题，不保存内部 RAG/记忆提示词。
3. 短期摘要更新失败时不产生摘要与消息窗口不一致。
4. 长期记忆召回避免因共享向量库全局 Top-K 导致用户记忆漏召回。
5. 知识库接口对请求字段进行安全校验，非法类型返回 400。

## 成功标准

- 相关单元测试覆盖每个修复场景并通过。
- `mvn -q test` 通过。
- 不改变现有 API 的成功响应结构和持久化集合结构。
